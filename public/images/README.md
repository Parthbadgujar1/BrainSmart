# Images

Drop the school's real artwork here (logo, hero photos, news thumbnails) and reference them as `/images/<file>`.

- Replace `/public/logo.svg` and `/public/favicon.svg` with the real logo (keep the same file names, or update `src/data/site.js`).
- Hero slides and news cards accept an optional `image` field (e.g. `image: '/images/spirit-night.jpg'`) in `src/data/site.js` and `src/data/news.js`. Without it a branded gradient is shown.
- Recommended sizes: hero 1920x800 (JPG/WebP, < 300 KB), news thumbnail 800x500.
